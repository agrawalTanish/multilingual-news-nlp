# 🌍 Multilingual Indian News NLP

> Processing, analyzing, and translating multilingual news data using NLP.

This project focuses on **Natural Language Processing (NLP)** techniques applied to multilingual Indian news data. It includes language detection, text preprocessing, and translation using modern machine learning models.

---

## 🚀 Overview

India has a diverse linguistic landscape. This project aims to:

* Detect language from news text
* Process and clean multilingual content
* Translate text into a common language
* Prepare data for further NLP tasks

---

## ✨ Features

* 🌐 Language detection
* 🔄 Multilingual translation
* 🧹 Text preprocessing & cleaning
* 🤖 Transformer-based models
* 📊 Data handling with Pandas

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/agrawalTanish/multilingual-news-nlp.git
cd multilingual-news-nlp
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```
